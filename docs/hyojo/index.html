平調の音階

平調は律旋で、五声は 宮 E・商 F#・角 A・徴 B・羽 C#。これに嬰商 G・嬰羽 Dを加えた七声で旋律が動きます。主音にあたる譜字は、メリを付けずに正律で安定して吹きます。

音名は国際式(A4 = 430 Hz を基準)。赤字の譜字は、平調でメリ・ハカリなどの例外的な奏法が付くもの(下の表を参照)。琵琶は弦と柱、筝は弦の名前です。琵琶・筝の調弦は、出典が見つからなかったため主音と音階から組んだ暫定値です。笙は合竹ではなく、竹(簧)1本ずつの音高です。

平調の例外的な奏法(メリ・ハカリ)

楽器譜字音高(正律 → この調子)この調子での奏法(このアプリでの再現)
篳篥舌G4 → F#4メリで半音下げる。 音頭で約70セント沈めてから立ち上げる。
篳篥凢C5 → C#5音階の上無(C#)に合わせる。 音頭で約60セント沈めてから立ち上げる。
篳篥六D5(変えない)五・工と行き来する境目で、約45セントなめらかに沈み込む。
篳篥四E5(変えない)音頭で約40セント沈めてから立ち上げる。
篳篥丄G5 → F#5メリで半音下げる。 音頭で約70セント沈めてから立ち上げる。
竜笛干E6(変えない)和(低音域)では、約32セント上から角度を変えてなめらかに着地する。
竜笛五F#5(変えない)高めに当たりやすいのを、顎を引いて約22セント抑え込み、正しい高さに合わせる。
竜笛夕A5(変えない)0.8秒以上伸ばすと、顎を引いて約90セント落とす(途中は階段状、フレーズの終わりは滑り台状)。
竜笛丅C#6(変えない)高めに当たりやすいのを、顎を引いて約20セント抑え込み、正しい高さに合わせる。
竜笛六D6(変えない)経過音(前後が別の音で1拍以内)のとき、メルで約60セント落とす。

セントは半音の 1/100。値はアプリの既定値で、gagaku/instruments.py の HICHIRIKI_MERI・RYUTEKI_MERI と gagaku/tunings.json で変えられます。
